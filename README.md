## 🌃 El expediente · ¿De qué trata este repositorio?

Este repositorio guarda la solución de la **Guía APE 4 de Introducción a la Programación Orientada a Objetos**. Son cinco ejercicios, cada uno resuelto dos veces: una en **Java** y otra en **C++**, para comparar cómo se ve la misma idea en los dos lenguajes.

En cada caso se crea una clase con sus atributos, se fabrican varias instancias en `main` y se trabaja con ellas: calcular, recorrer, modificar e imprimir. Como en cualquier investigación de Gotham, primero se arma el plano (la clase) y después salen los agentes a la calle (los objetos).

## 🗂️ Los 5 casos de Gotham

| Caso | Expediente | Clases involucradas | Lo que se investiga |
| :---: | :--- | :--- | :--- |
| **01** | **Notas del curso** | `Estudiante` | Promedio de 5 estudiantes, estado Aprobado / Supletorio / Reprobado y conteo de aprobados. |
| **02** | **Inventario de una tienda** | `Producto` | Venta de 3 unidades de dos productos, alerta de «Reponer» y valor total del inventario. |
| **03** | **Veterinaria** | `Mascota` | Alerta «Revisar peso» sobre 20 kg y el misterio de `Mascota m4 = m1;` |
| **04** | **Cuenta de ahorro** | `Cuenta` | Depósitos de 50 por mes con `while` hasta llegar a 500. |
| **05** | **Biblioteca** | `Libro`, `Socio` | Préstamos entre dos socios y conteo de libros disponibles. |

> [!IMPORTANT]
> **El caso más peligroso es el 03.** `Mascota m4 = m1;` no crea otra mascota: copia la **referencia**. `m1` y `m4` son dos nombres para el mismo objeto, así que al cambiar `m4.edad` también cambia `m1.edad`. En C++ se reproduce con una referencia `Mascota& m4 = m1;`.

## 🛠️ Batiprotocolo · Cómo ejecutar

Entrar a la carpeta del caso, por ejemplo `cd Ejercicio1`.

```bash
# ☕ Java
javac Ejercicio1.java
java Ejercicio1

# ⚙️ C++
g++ Ejercicio1.cpp -o ejercicio1
./ejercicio1          # en Windows: ejercicio1.exe
```

Cambia el número para cualquiera de los otros cuatro casos.

## 🧰 El Batcinturón de la POO

Batman no carga cualquier cosa en su cinturón, solo lo que funciona. Estos son los gadgets que se usaron en los cinco casos.

| Gadget | Concepto | En Gotham sería… | Dónde aparece |
| :--- | :--- | :--- | :--- |
| 📐 **Planos de Wayne Tech** | Clase | El diseño del Batimóvil antes de fabricarlo. | Todos los casos |
| 🚗 **Batimóvil** | Objeto / instancia | El Batimóvil ya construido y listo para salir. | `new Estudiante()`, `new Producto()`… |
| 🧾 **Ficha del expediente** | Atributos | Los datos de cada sospechoso: nombre, edad, peso. | `nombre`, `saldo`, `stock`… |
| 🔁 **Ronda de patrullaje** | `for` sobre un arreglo | Revisar uno por uno a todos los agentes. | Casos 01, 02, 03 y 05 |
| ⏳ **Vigilancia nocturna** | `while` | Seguir en guardia hasta que se cumpla la condición. | Caso 04 |
| 🪞 **Dos identidades** | Referencias | Bruce Wayne y Batman: dos nombres, una sola persona. | Caso 03 (`m4 = m1`) |
